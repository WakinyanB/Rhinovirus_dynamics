# Readme

Data & Codes for:<br>

**Leveraging perturbations to infer the population dynamics of human rhinovirus and interaction of influenza A virus**

*Wakinyan Benhamou, Emily Howerton, Sang Woo Park, Cécile Viboud, C. Jessica E. Metcalf and Bryan T. Grenfell*

- **Root directory** <br>
Plot studied regions (`Map_North_America.R`)<br>
Plot time series data and cross-wavelet analyses (`Plot_US_CA_Data_and_cross_wavelet_analysis.R`)

- **`Data/`** 
  - `Canada/`<br>
    Raw time series (`data_canada_resp.csv`)<br>
    Rescaled time series (`data_canada_province.RData`, as generated by `Process_data_Canada.R`)<br>
    Census data (`Canada_pop_size.csv`)
    
  - `Google_mobility/`<br>
    Google COVID-19 Community Mobility Reports for the US and Canada and corresponding R scripts
  - `Simulation/`<br>
    Simulated data (scenarios 1, 2 and 3, and scenario extensions 'shift' and 'kick'), as well as R scripts to generate them; we also explored different parameter values for scenario 2 (sensitivity)
  - `USA/`<br>
    US time series data (`Data_USA.RData`, see below for raw data) and census data (`State_2020_pop.csv`)
    - `FluView/` (raw data for IAV)
    - `NREVSS/` (raw data for RV/EV)
      
- **`Fit/`**<br>
  R files to fit SIRS (or SEIRS) models to RV/EV time series from the US and Canada; we consider current IAV incidence or lagged sums with a lag of 1, 3 or 5 weeks<br>
  R files to plot fitted model results (`Results_fit_USA_Canada.Rmd`)<br>
  R files to compare nested models using compute approximate leave-one-out cross-validation using Pareto smoothed importance sampling (`LOO_CV_comparison.R`)
  - `LOO_refit/`<br>
    Leave-one-out cross-validation: model refits to evaluate exact log-likelihood for observations with Pareto k-values >0.7
  - `Simulation_study/`<br>
  Fits the model to all simulated data
  - `Stan_models/`<br>
    Stan files to fit SIRS models to data<br>
    npi=non-pharmaceutical interventions (includes (post-)pandemic period)<br>
    vi=viral interaction (estimates IAV effect on RV)
    - `Estim_NPI/` (estimates weekly effects of non-pharmaceutical interventions, without using mobility data)
    - `SEIRS/` (adds an exposed stage E in the compartmental model)
    - `LOO/` (exact Leave-one-out cross-validation)
